# إدارة تجار علاكة سوق

لوحة PWA عربية مستقلة للتاجر، مرتبطة ببيئة Convex Production الخاصة بعلاكة سوق. الرابط لا يمنح صلاحية؛ جميع عمليات المتجر تتحقق من جلسة التاجر وملكية `storeId` داخل Convex.

## التطوير

```bash
npm ci
npm test
npm run dev
```

متغير `VITE_CONVEX_URL` عنوان عام وليس سرًا. مفتاح Pushy السري محفوظ في بيئة Convex Server-side فقط ولا يدخل في هذا المستودع.
